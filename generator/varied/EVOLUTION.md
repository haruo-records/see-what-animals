# 生成器の更新方針（第3世代）

A群12体・B群12体から得た知見を、生成器の恒久的な規則として反映する。
個体の派生ではなく、生成規則そのものの更新。

## 診断（数値で裏付け済み）

「弱い」とされた中段の型は、二つの計測量で説明できる。

- **dominance**：最大部材が全体質量に占める割合。高いほど「大きな塊＋添え物」
- **link density**：リンク数÷ノード数。低いほど「繋がらず、近接や関係だけで一体を装う」

弱い個体（B07 related pair=0.43 / B08 simple outside=0.40 / A08 detached=0.33 / A10 size contrast=0.25）は、いずれも **link density が 0.5 未満**。

強い個体（A07 large cavity=0.90 / B03 crossed cavity=0.87 / A09 plane+solid=0.82 / B10 raised centre=0.77）は、いずれも **0.7 以上**。

## 反映する規則

### 規則1 — 接続密度の下限
すべての新カテゴリは link density ≥ 0.6 を満たすこと。部材は近接・関係でなく、実際の接続で一体になる。「離れた塊を小部材が関係づける」型（B07）「外形の中に無関係な内部が浮く」型（B08）は作らない。

### 規則2 — 単一支配部材の上限
最大部材の質量比 ≤ 0.5。一つの塊が全体を占め、残りが添え物になる構図（A10 size contrast=0.49、A08=0.43）を禁じる。大小の対比は「役割の対比」で出す。

### 規則3 — 保持する方向（上段・下段）
接続・貫通・相互支持・展開・再接続で一体になる型は、A群B群を通じて strong。これらを新カテゴリの母体にする：
- 貫通して別位置で再接続（A05 through, B03 crossed cavity, B12 flow rejoin）
- 相互支持・多点支持（A06 mutual, B04 multi-height）
- 空洞を部材が横切る（A07 cavity, B03）
- 低く広がり中央が立つ／上部が展開（B09 branching, B10 raised）

### 規則4 — 減らす方向（中段）
- 大きな塊＋小さな添え物（A10, B05, B07）
- 外形と内部が無関係（B08）
- 意味なく散る離れた小部材（A08）

これらは新カテゴリから除外。ただし「離れていても一体」は規則1を満たす限りで残す
（B群の detached は接続で救えないので、代わりに「離れた部材どうしが第三の部材で
実際に連結される」形にして密度を確保する）。

### 規則5 — 描画仕様は固定
アイソメ・白背景・フラット・現行パレット・濃いグレー輪郭線・薄い影・顔なし・2〜3色。
変更しない。

## 新カテゴリ（第3世代・12種）

すべて規則1・2を満たすよう設計。中段型を含まない。

1. 三重貫通環 — 環を3本の部材が別々の角度で貫く
2. 段違い橋 — 高さの違う2つの支点を渡る、途中で分岐して再合流
3. 巻き込み — 一本の体が内側へ巻き込み、末端が中心で別部材と噛む
4. 三点相互支持＋横架 — 3本が支え合い、その上に横材が渡って全体を締める
5. 貫通して展開 — 1本が塊を貫き、抜けた先で複数方向へ枝分かれ
6. 二重らせん支持 — 2本のらせんが絡んで一つの柱を成す
7. 空洞連鎖 — 空洞を持つ部材が2つ連なり、内部を1本が貫いて繋ぐ
8. 片持ち＋吊り — 片持ちの梁から別の部材が吊られ、二段の力の経路
9. 折り重なり — 板が二度折り返し、各面が別方向を向いて噛む
10. 低く広がり多点で立つ — 横長の体が3点で接地し、中央が持ち上がる
11. 収束と再展開 — 複数の体が一点へ収束し、そこから別数の体が出る
12. 貫入格子 — 2枚の面が互いに切り欠きで噛み合う（融合した一体）
